# PictureCrawling_Python

#### 📢 크롤링한 사진을 패딩 처리 및 사이즈를 조정한다.   
🖥️ 사용언어 : Python, Selenium  

<br>

1. selenium_go.py
   > Python, Selenium 사용하기.
2. opencv1.py
   > Python, OpenCV 사용하기.
3. dogcrawling.py, dogcrawling_2.py, dogcrawling_do.py
   > Google 에서 검색어를 통해 강아지 사진을 크롤링한다.
4. dog_padding.py, dog_paddingone.py
   > Google 에서 검색어를 통해 크롤링한 강아지 사진을 padding 처리 한다.
5. size.py
   > 크롤링한 사진의 사이즈를 조정한다.
